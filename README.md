# Dicke superradiance with dephasing and spontaneous emission

This repository contains the data-generation and plotting code retained for the
paper on finite-size Dicke superradiance in the presence of local dephasing and
spontaneous emission. The numerical routines combine stochastic trajectories
with mean-field calculations.

The repository is intentionally limited to routines that contribute to the
figures currently used in the paper and its appendix. The main-text Figure 1
workflow is **not included**: the former Figure 1 notebook was obsolete and the
current Figure 1 is produced elsewhere.

## Repository layout

```text
code/
  MonteCarloMF.jl             Core Monte Carlo and mean-field routines
  AnalyticResults.jl          Shared analytical phase-boundary expression
  PlotSetup.jl                Matplotlib and LaTeX plotting configuration
  style.jl                    Shared colors, legends, and labels
  plot_appendix.jl            Plotting methods used by AppFigs.ipynb
  generate_*.jl               Data-generation entry points
  fig2_mean_field.ipynb       Final main-text Figure 2
  fig3_mean_field.ipynb       Final main-text Figure 3
  plot_beta_mc.ipynb          Beta/phase-boundary figure
  AppFigs.ipynb               Additional appendix figures
  Makefile                    Data-generation dependency graph

plot_data/                    Generated JLD2 datasets
data/                         Generated PDF figures
```

## Requirements

The code has been tested with Julia 1.12. It uses the following Julia packages:

- `DifferentialEquations`
- `OrdinaryDiffEq`
- `Distributions`
- `JLD2`
- `PyPlot`
- `PyCall`
- `LsqFit`
- `IJulia` for running the notebooks

They can be installed in the active Julia environment with:

```bash
julia -e 'using Pkg; Pkg.add(["DifferentialEquations", "OrdinaryDiffEq", "Distributions", "JLD2", "PyPlot", "PyCall", "LsqFit", "IJulia"])'
```

`PlotSetup.jl` configures Matplotlib to render text with LaTeX. A working LaTeX
installation containing the `physics`, `bm`, and `amsfonts` packages is
therefore required to reproduce the PDF figures.

The repository currently does not contain a `Project.toml`, so commands use the
active Julia environment.

## Generate the data

From the repository root, create the output directories and generate every
retained dataset with:

```bash
mkdir -p plot_data data
JULIA_NUM_THREADS=auto make -C code data
```

Some Monte Carlo scans are computationally expensive. Existing JLD2 targets are
not regenerated by `make` unless their source dependencies are newer. To rerun
one calculation directly, execute its generator from the `code` directory:

```bash
cd code
JULIA_NUM_THREADS=auto julia generate_dephasing_main_scan.jl
```

Generator functions also accept keyword arguments for smaller test scans or
alternative parameters. For example:

```julia
include("generate_dephasing_main_scan.jl")

generate_dephasing_main_scan(
    Ns = [1_000, 10_000],
    rs = range(0.0, 2.0, 20),
    N_traj = 100,
    outfile = "../plot_data/dephasing_test.jld2",
)
```

## Generate the figures

Open the notebooks with their working directory set to `code/`. Run their cells
in order.

| Notebook | Current output | Purpose |
|---|---|---|
| `fig2_mean_field.ipynb` | `data/fig2.pdf` | Final main-text Figure 2, including its insets |
| `fig3_mean_field.ipynb` | `data/fig3.pdf` | Final main-text Figure 3 |
| `plot_beta_mc.ipynb` | `data/figS1.pdf` | Beta scaling and analytical-boundary figure |
| `AppFigs.ipynb` | `data/figS5.pdf`, `data/small_spontaneous.pdf` | Additional appendix figures |

`AppFigs.ipynb` imports all of its reusable plotting methods from
`plot_appendix.jl`.

## Reproducibility notes

- Randomized Monte Carlo calculations are not globally seeded, so regenerated
  datasets will show ordinary sampling variation.
- The default generators use multithreading where applicable. Set
  `JULIA_NUM_THREADS` explicitly when recording computational details.
- Generator defaults reproduce the retained production scans and can require
  substantial CPU time.
- Relative input and output paths assume that scripts and notebooks are run
  from the `code/` directory, or through `make -C code`.
